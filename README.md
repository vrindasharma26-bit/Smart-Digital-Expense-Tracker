# Smart-Digital-Expense-Tracker
A C++ based Smart Digital Expense Tracker with Monthly Budget Prediction.

## Introduction
Smart Digital Expense Tracker is a C++ project designed to help users manage daily expenses and monthly budgets.

## Objectives
- To track daily expenses.
- To manage monthly budgets.
- To check spending history.
- To predict future expenses.
- To improve money management.

## Features
1. User Registration
2. User Login
3. Add Daily Expense
4. View Expense History
5. Category-wise Expense
6. Monthly Expense Report
7. Set Monthly Budget
8. Budget Warning
9. Expense Prediction
10. Search Expense
11. Delete Expense
12. File Handling

## Technologies Used
- Programming Language: C++
- Concepts: Functions, Loops, Arrays, Structures, Strings and File Handling.
- Compiler: Online GDB

## Conclusion
This project helps users track their expenses, manage their budget and understand their spending habits.
